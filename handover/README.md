# Sprint 2 handover

This folder contains the standalone Codex task for Sprint 2.

Before using it, complete the Sprint 1 physical Android acceptance test, including a stable ten-minute conversation, interruption, mute, navigation cleanup, microphone denial, and network-loss behavior.

To begin Sprint 2, open the repository in Codex and paste the contents of `SPRINT_2_CODEX_PROMPT.md` as the task. Keep `BUILD_PLAN.md` and `AGENTS.md` in the repository so Codex can read the authoritative project instructions.
